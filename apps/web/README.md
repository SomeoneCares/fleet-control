# apps/web

React + TypeScript (Vite) client for Fleet Control. Not scaffolded yet: the first screens to build are
Instances (with the Connect drawer), Blueprints, ApplyPlan and Drift — see `design/` for the artboards and
`design/DESIGN.md` for tokens. Configure Tailwind from those tokens; do not hand-copy colours.
The API it talks to is `apps/api` (`/api/v1/...`).
